# 在 DLDR 使用 DLsite Play

DLDR 可在獨立的應用程式視窗中開啟官方 DLsite Play，先線上聆聽已購作品，再決定
是否下載。網頁播放、音軌與字幕由官方播放器提供；已下載作品繼續使用 DLDR
現有的本機播放器。

1. 點側欄的 **DLsite Play**，或作品卡片的 **DLPLAY**（已下載作品也可使用）。
2. 選擇對應的 DLDR 下載帳號，按 **開啟 DLsite Play**。從卡片進入時只列出該
   作品的啟用擁有者帳號。
3. 首次在官方頁面使用相同帳號的 **DLsite／viviON ID 與密碼**登入，依官方
   要求完成驗證。這個視窗的登入狀態與 DLDR／CLI 的憑證分開保存。
4. 在官方作品頁聆聽。右上角會有 DLDR 面板，顯示該作品的 RJ／BJ／VJ 編號、
   下載狀態及 **下載至 DLDR** 按鈕。
5. 點按鈕才會加入 DLDR 下載佇列。需要下載帳號的驗證碼時，DLDR 主視窗會
   自動移到前景；進度、暫停與取消可在左下角的下載進度面板操作。

作品卡片的操作列固定分成兩個按鈕：未下載為 **DLPLAY｜下載**，已下載為
**DLPLAY｜打開目錄**。下載按鈕會直接加入既有佇列，排隊／下載中時停用；本機
匯入且沒有購買帳號的作品不提供 DLPLAY 或下載。本機播放器仍可由已下載卡片
的空白處開啟。檔案大小右側保留 DLsite 商品連結，目錄按鈕集中在操作列。

開啟作品不會下載完整作品；線上播放仍會使用網路與官方播放器的瀏覽器快取。
已下載或正在下載的作品會停用新增下載按鈕，避免重複下載。暫停／失敗作品會
提供續傳／重試，沿用原佇列的路徑與解壓設定。新下載沿用目前下載設定，支援
既有的平行下載與限速。原佇列指定另一個帳號時，請回到 DLDR 的下載佇列處理。

官方作品頁的面板只接受已同步到 DLDR、且屬於所選啟用帳號的作品。如果剛購買
的作品無法下載，先在 DLDR 設定中同步該帳號。尚未設定作品庫時，請到「設定 →
下載設定」設定保存位置。

每個 DLDR 帳號有獨立的瀏覽器資料目錄；同帳號重開入口會重用現有視窗。
關閉官方視窗會停止該視窗的線上播放，已加入 DLDR 的下載仍繼續。
關閉 DLDR 主視窗會連帶關閉官方視窗。瀏覽器會依官方 Cookie 有效期限保存
登入狀態；過期後需重新登入。要登出官方播放器，請使用官方網站的登出操作。
`dldr logout` 清除的是 DLDR 下載憑證，不會清除這份官方瀏覽器登入狀態。

目前以 Linux 驗證，程式支援 Linux／Windows 的獨立瀏覽器資料目錄；Windows
仍需原生登入與媒體驗收，macOS 尚未啟用此入口。Google、X 等第三方社群登入
目前不支援；請使用官方 ID／密碼。官方驗證頁與音檔格式的相容性仍取決於系統
WebView，實帳播放需要使用者登入驗收。面板語言沿用開啟視窗時的 DLDR 語言；
變更語言後請關閉並重開官方視窗。

這是載入官方網站的整合，官方頁面改版可能需要更新作品路徑／面板適配。技術
邊界見 [架構說明](architecture.md#official-dlsite-play)。
